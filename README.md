# Odeli

> **A lightweight, AI-native, agentic IDE for software and embedded systems engineering.**

> **Status:** 🚧 Early Development

Odeli is an open-source, cross-platform integrated development environment (IDE) built from the ground up with AI as a first-class capability. Designed for speed, extensibility, and native performance, Odeli aims to provide an intelligent development experience for modern software engineering, systems programming, and embedded systems engineering.

Unlike traditional editors that treat AI as an extension, Odeli is being designed around autonomous AI agents that can understand projects, plan complex tasks, execute development workflows through secure tools, and collaborate with developers while keeping them in full control.

## Vision

Our mission is to build the next generation of development tools—an IDE that combines native performance, intelligent automation, and professional engineering workflows in a single platform.

Odeli is designed for developers and engineers building:

* Web applications
* Desktop applications
* Mobile applications
* Backend services
* Operating systems
* Systems software
* Embedded firmware
* Robotics
* Internet of Things (IoT) devices
* Electronics and hardware projects

## Principles

Odeli is being built around a few core principles:

* **Native First** — Fast, lightweight, and built in Rust.
* **AI Native** — AI is a core capability, not an afterthought.
* **Developer Control** — AI actions are transparent and tool-driven.
* **Extensible** — Designed with plugins and customization in mind.
* **Cross-Platform** — Linux, Windows, and macOS.
* **Engineering Focused** — Built for software developers, systems programmers, and embedded engineers.
